# OpenPulse AI

**دستیار هوشمند و دوزبانه اخبار تلگرام — پروژه متن‌باز**

OpenPulse AI یک پروژه پایتون ماژولار است که برای دریافت اخبار از منابع مجاز، تشخیص موارد تکراری، آماده‌سازی خلاصه‌های هوشمند و انتشار کنترل‌شده در تلگرام طراحی می‌شود.

> **وضعیت فعلی: مرحله اول زیرساخت.** اسکلت ربات تلگرام و ابزارهای توسعه آماده‌اند. دریافت خبر، پردازش هوش مصنوعی، ذخیره‌سازی و انتشار در مراحل بعدی پیاده‌سازی خواهند شد.

## قابلیت‌های برنامه‌ریزی‌شده

- رابط ربات تلگرام و دستورات مدیریتی
- اتصال ماژولار به منابع خبری مجاز
- تشخیص خبرهای تکراری و حفظ لینک منبع
- خلاصه‌سازی و ترجمه فارسی و انگلیسی
- اتصال اختیاری به OpenAI
- صف بازبینی انسانی پیش از انتشار
- تست خودکار و GitHub Actions

## راه‌اندازی

### پیش‌نیازها

- Python نسخه 3.11 یا بالاتر
- توکن ربات تلگرام از [@BotFather](https://t.me/BotFather)
- کلید OpenAI برای قابلیت‌های هوش مصنوعی در مراحل بعد (اختیاری)

### نصب

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/OpenPulse-AI.git
cd OpenPulse-AI
python -m venv .venv

# ویندوز PowerShell
.venv\Scripts\Activate.ps1

# لینوکس و macOS
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -e ".[dev]"
```

### تنظیم توکن

فایل نمونه را کپی کنید:

```bash
# Linux/macOS
cp .env.example .env

# Windows PowerShell
Copy-Item .env.example .env
```

سپس مقدار `TELEGRAM_BOT_TOKEN` را در فایل `.env` قرار دهید. این فایل نباید در Git ثبت شود.

### اجرا

```bash
python -m openpulse
```

در تلگرام وارد ربات شوید و دستور `/start` را بفرستید.

## متغیرهای محیطی

| متغیر | اجباری | توضیح |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | بله | توکن دریافتی از BotFather |
| `OPENAI_API_KEY` | خیر | برای اتصال هوش مصنوعی در مرحله بعد |
| `OPENAI_MODEL` | خیر | نام مدل مورد استفاده در اتصال آینده |
| `LOG_LEVEL` | خیر | سطح گزارش‌گیری؛ پیش‌فرض INFO |

## ساختار پروژه

```text
src/openpulse/
├── bot/                 # دستورات و هندلرهای تلگرام
├── core/                # منطق اصلی و پردازش خبر
├── integrations/        # اتصال به سرویس‌های خارجی
├── config.py            # تنظیمات محیطی
└── main.py              # نقطه شروع برنامه
tests/                   # تست‌های خودکار
```

## اصول استفاده مسئولانه

- فقط از منابع عمومی، مجاز یا دارای مجوز استفاده کنید.
- شرایط استفاده تلگرام، حقوق ناشر و محدودیت نرخ درخواست را رعایت کنید.
- لینک منبع اصلی هر خبر را حفظ کنید.
- خلاصه تولیدشده توسط هوش مصنوعی را گزارش تأییدشده انسانی معرفی نکنید.
- تا زمان اثبات کیفیت فیلترها، پیش از انتشار بازبینی انسانی داشته باشید.
- توکن‌ها و کلیدهای محرمانه را داخل کد یا مخزن قرار ندهید.
